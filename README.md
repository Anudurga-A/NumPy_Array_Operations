# NumPy_Array_Operations
# Veda Technology - NumPy Array Operations

## Project Overview
This project demonstrates basic mathematical operations on NumPy arrays using Python. It helps beginners understand how NumPy performs numerical calculations efficiently.

## Objective
To create two NumPy arrays and perform addition, subtraction, multiplication, and division operations.

## Technologies Used
- Python
- NumPy
- Jupyter Notebook

## Operations Performed
- **Addition:** Adds corresponding elements of two arrays.
- **Subtraction:** Subtracts corresponding elements.
- **Multiplication:** Multiplies corresponding elements.
- **Division:** Divides corresponding elements.
- **Array Shape:** Displays the shape of both arrays.

## Sample Arrays
Array A: `[10, 20, 30, 40]`

Array B: `[2, 4, 5, 8]`

## Sample Output
```text
Addition: [12 24 35 48]
Subtraction: [ 8 16 25 32]
Multiplication: [ 20  80 150 320]
Division: [5. 5. 6. 5.]
Shape of A: (4,)
Shape of B: (4,)
```

## How to Run
1. Install Python on your system.
2. Install NumPy using `pip install numpy`.
3. Open Jupyter Notebook.
4. Copy the Python code into a notebook cell.
5. Run the cell to view the results.

Learned how to create NumPy arrays, perform vectorized mathematical operations, and check array shapes using Python.
